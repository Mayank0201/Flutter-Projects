## Games with Difficulty Scaling Issues

### 🔴 Critical Plateau Points

#### 1. Circuit Guide  *(corrected 2026-07-18)*
- **Current Max:** **6x6** grid + 4 targets (hardcoded if/else ladder, `circuit_guide_beta.dart` 111-133; targets also `clamp(1, W)` at line 161)
- **Issue:** Grid/target growth stops at level 36; every level after is 6×6 / 4 targets → PLATEAU
- **Progression (verified):**
  - Early levels ramp 3x3 → 4x4 → 5x5 with 1→3 targets
  - `_currentLevel < 28`: 5x5, 3 targets
  - `_currentLevel < 35`: 5x5, 4 targets
  - **Level index ≥ 35 (i.e. "Level 36"+): 6x6, 4 targets → PLATEAU**
- *(The earlier "5x5 cap, plateau ~L28" was wrong — real max is 6x6 and the plateau is at L36.)*

#### 2. Mine Finder
- **Current Max:** 13x13 grid (hardcoded clamp)
- **Formula:** `gridSize = (5 + (levelIndex ~/ 3)).clamp(5, 13)`
- **Issue:** Hard cap reached around level ~24, no scaling beyond that
- **Plateau Point:** Level 24+

#### 3. Pattern Lock
- **Current Max:** 5x5 grid (25 dots)
- **Issue:** Pattern length clamped to grid size; cannot scale beyond 5x5
- **Progression:**
  - Levels 0-4: 3x3 grid, pattern length increases
  - Levels 5-9: 4x4 grid
  - **Levels 10+: 5x5 grid (max) → PLATEAU**

#### 4. Sudoku
- **Current System:** ~60+ hardcoded levels only
- **Issue:** No procedural generation; just cycles through fixed list
- **Progression:**
  - Levels 0-5: 4x4 grids (6 levels)
  - Levels 6-14: 6x6 grids (9 levels)
  - Levels 15+: 9x9 grids (cycles/wraps)
- **Limitation:** After ~60 levels, progression stalls

#### 5. Spectrum
- **Current Max:** 10x11 grid
- **Issue:** Scaling slows significantly after level 35
- **Progression:**
  - Levels 0-4: 3x3
  - Levels 5-9: 4x4
  - Levels 10-14: 5x5
  - Levels 15-19: 6x6
  - Levels 20-24: 7x7
  - Levels 25-29: 8x8
  - Levels 30-34: 9x9
  - Levels 35-39: 9x10
  - Levels 40-44: 10x10
  - **Levels 45+: 10x11 → PLATEAU**

### ⚠️ Limited Scaling

#### 6. Chimp Test
- **Current Max:** 12x12 grid
- **Issue:** Grid size caps at 12x12; number count grows but grid doesn't
- **Formula:** `gridSize = (9 + extra ~/ 5).clamp(9, 12)`
- **Progression:**
  - Levels 0-29: Hardcoded levels (3x3 to 9x9)
  - Levels 30-39: Extra 10 levels (mixed difficulty)
  - **Levels 40+: Infinite with 12x12 cap**

#### 7. Star Battle  *(corrected 2026-07-18)*
- **Current System:** **Fully procedural from level 0** (`_loadLevel` → `generateProceduralLevel(n, Random(_levelIndex + 8734))`, `star_battle_screen.dart` 749-762)
- **⚠️ Dead code:** the `const _kLevels` list (~65 `QueensLevel` entries, line 23) is **never referenced anywhere** — safe to delete.
- **Issue:** grid size caps at 9x9 from level 50 onward → soft plateau (difficulty only from procedural variety after that)
- **Progression (verified):**
  - `< 5`: 5x5 · `< 15`: 6x6 · `< 30`: 7x7 · `< 50`: 8x8 · `≥ 50`: 9x9
- *(The earlier "44 hardcoded levels then procedural 9→10" was wrong on both counts.)*

## Games with Good Scaling ✅

#### 1. Grid Path
- **Scaling:** Infinite procedural generation
- **Progression:**
  - Levels 0-4: 3x3 grid, 2-4 waypoints
  - Levels 5-14: 4x4 grid, 3-5 waypoints
  - Levels 15-29: 5x5 grid, 5-7 waypoints

## Recommended Scaling Improvements

### Priority 1 (High Impact)
| Game | Current Cap | Recommended Cap | Action |
|------|------------|-----------------|--------|
| Circuit Guide | 5x5 + 4 targets | 7x7 + 6 targets | Remove hardcoded max, enable procedural generation |
| Mine Finder | 13x13 | 16x16 or infinite | Increase clamp and add procedural scaling |
| Pattern Lock | 5x5 (25 dots) | 6x6+ (36+ dots) | Remove grid size cap, allow infinite pattern length |

### Priority 2 (Medium Impact)
| Game | Current Cap | Recommended Action |
|------|------------|-------------------|
| Sudoku | ~60 hardcoded levels | Implement procedural puzzle generation for levels 60+ |
| Spectrum | 10x11 | Extend to 12x12+ with procedural generation |
| Chimp Test | 12x12 grid cap | Increase to 14x14 or higher |

### Priority 3 (Enhancement)
- **Grid Path:** Already excellent; consider adding optional harder modes (more walls, fewer waypoints)
- **Odd Color Out:** Already good scaling; consider adding time pressure at higher levels
- **Colour Link:** Already good; consider higher color counts at extreme levels
- **Color Flood:** Already good; consider tighter move budgets at higher levels

## Implementation Notes

### For Hardcoded-to-Procedural Transition Games
- Ensure smooth difficulty jump when switching from hardcoded to procedural levels
- Test that procedural generation maintains consistent difficulty curve

### For Games with Clamps
- Replace `.clamp(min, max)` with conditional scaling that continues beyond current max
- Example: `(5 + (levelIndex ~/ 3)).clamp(5, 13)` → `max(5, 5 + (levelIndex ~/ 3))`

### For Infinite Scaling Games
- Monitor performance at extreme grid sizes (15x15+)
- Consider optimization for larger grids if needed

# SCALING STRATEGY IMPROVEMENTS FOR ALL 12 ACTIVE GAMES

**Problem:** Current scaling just makes games "harder" (bigger grid, more items) without adding mechanical variety or unique progression.

**Solution:** Add secondary mechanics and evolving challenges so each game stays fresh through all levels.

---

## 1. Grid Path (zip)

**Current Scaling:** Grid size + waypoint count + walls  
**Already Good:** Infinite scaling with procedural generation ✅

**Enhancement Ideas:**
- Levels 30-49: Add "locked" waypoints (must pass through specific points)
- Levels 50-70: Add "bouncing walls" (walls that redirect path)
- Levels 70+: Add checkpoint limits (must reach waypoint in X moves)
- Add time pressure variants at high levels

**Implementation:** Modify level generation to include waypoint constraints

## 2. Odd Color Out (oddcolor)

**Current Scaling:** Grid size + decreasing color difference (0.10 → 0.04)  
**Problem:** Color difference eventually becomes imperceptible; just harder, not different

**Scaling Strategy (Evolution Model):**

| Levels | Grid | Mechanic | Secondary Challenge |
|--------|------|----------|---------------------|
| 0-9 | 2x2 to 3x3 | Find single off-color tile | None |
| 10-19 | 4x4 | Single off-color + more subtle | 20-second time limit |
| 20-29 | 5x5 | Single off-color | 15-second time limit |
| 30-39 | 6x6 | **2 tiles that are slightly different from each other** | Identify which pair is different; 12-second limit |
| 40-49 | 7x7 | **3 shades**: find the middle shade | Rank shades from lightest to darkest |
| 50-59 | 8x8 | Off-color tile + position memory | Tile moves to random spot after 3 sec; must remember location |
| 60-69 | 8x8 | **Moving grid**: tiles shift positions between rounds | Find off-color while tiles rearrange |
| 70+ | 9x9 | **Multiple conditions**: off-color + wrong shape + wrong saturation | Master all three perception types |

**Why This Works:**
- Doesn't just decrease color difference (avoids imperceptible ceiling)
- Adds secondary mechanics (time, memory, movement, multiple attributes)
- Each tier feels like a new game, not just harder

## 3. Chimp Test (chimp)

**Current Scaling:** Grid size 3-12, number count 4-60  
**Already Decent:** Natural progression with parameters

**Enhancement Ideas:**
- Levels 0-10: Show all numbers at once (current)
- Levels 11-20: Numbers fade after 2 seconds (memory component)
- Levels 21-30: Numbers appear in random order (spatial memory)
- Levels 31-40: **Numbers flash briefly** (1 second), player must recall positions
- Levels 41-50: **Distractors**: false numbers appear and disappear
- Levels 50+: **Mixed modes**: combine fading + distractors + grid size growth

**Implementation:** Add visibility duration parameter to level generation

## 4. Star Battle (queens)

## Summary: Scaling Philosophy

**Key Principle:** Don't just make it harder — make it different.

**Techniques Used Across All Games:**

1. **Time Pressure** — Adds urgency, changes strategy (used in: Odd Color Out, Chimp Test, Spectrum, Word Hive, Pattern Lock, Colour Link, Circuit Guide)

2. **Secondary Mechanics** — Add new rules/constraints (Odd Color Out: multiple tiles → shading → memory; Mine Finder: blind mode; Spectrum: multi-gradient; Sudoku: variants)

3. **Grid Evolution** — Not just bigger, but different shapes/structures (Asymmetric grids in Star Battle; irregular regions in Sudoku variants)

4. **Parameter Combinations** — Combine mechanics at high levels (Circuit Guide: time + power + damage + grid size)

5. **Pattern Complexity** — Teach new skills per tier (Pattern Lock: simple → overlapping → multiple sequences)

6. **Hidden Information** — Hide data that was previously visible (Mine Finder: blind mode; Word Hive: hidden letters)

7. **Rotation/Movement** — Add dynamic elements (Word Hive: letter rotation; Odd Color Out: grid shifts)

**Result:** Each game scales to 70+ levels without feeling repetitive, each tier teaches something new, and the core mechanic evolves rather than just amplifying.
