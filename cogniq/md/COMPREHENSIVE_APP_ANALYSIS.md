## Executive Summary

CogniQ is a well-engineered logic puzzle app with solid fundamentals (8/10 overall quality). The codebase demonstrates thoughtful design decisions, excellent error handling, and polished animations. However, growth is constrained by:

1. **Game Balance:** Heavily skewed toward logic puzzles (75%), weak in vocabulary/reaction games
2. **Scaling Issues:** 4 games plateau in difficulty (Circuit Guide, Mine Finder, Pattern Lock, Sudoku cycles)
3. **Accessibility Gaps:** No semantic labels for screen readers, font scaling edge cases
4. **Small Issues:** Haptic feedback bug, FogOverlay performance, missing skeleton loaders

**Strategic Direction:** Double down on logic puzzle excellence rather than forcing genre diversity. Add 4-5 high-quality logic games (Kakuro, Cipher Decoder, Hitori, Slitherlink) to reach 17-20 games with better mechanical variety.

# PART 1: DIFFICULTY SCALING ANALYSIS

## Overview

Analysis of difficulty progression and scaling limitations across all 12 active games.

### Games with Critical Plateau Points

#### Circuit Guide
- **Current Max:** 5x5 grid + 4 targets (hardcoded)
- **Issue:** Game becomes unchallenging after level ~28
- **Progression:**
  - Levels 0-4: 3x3 grid, 1 target
  - Levels 5-7: 3x3 grid, 1 target
  - Levels 8-11: 3x3 grid, 2 targets
  - Levels 12-16: 4x4 grid, 2 targets
  - Levels 17-21: 4x4 grid, 3 targets
  - Levels 22-27: 5x5 grid, 3 targets
  - **Levels 28+: 5x5 grid, 4 targets → PLATEAU**
- **Fix:** Remove hardcoded max, allow 6x6, 7x7 grids; enable procedural generation

#### Mine Finder
- **Current Max:** 13x13 grid (hardcoded clamp)
- **Formula:** `gridSize = (5 + (levelIndex ~/ 3)).clamp(5, 13)`
- **Issue:** Hard cap reached around level ~24, no scaling beyond that
- **Fix:** Increase clamp from 13 to 16+ or remove entirely

#### Pattern Lock
- **Current Max:** 5x5 grid (25 dots)
- **Issue:** Pattern length clamped to grid size; cannot scale beyond 5x5
- **Progression:**
  - Levels 0-4: 3x3 grid
  - Levels 5-9: 4x4 grid
  - **Levels 10+: 5x5 grid (max) → PLATEAU**
- **Fix:** Remove 5x5 cap, allow 6x6+ grids with infinite pattern length scaling

#### Sudoku
- **Current System:** ~60+ hardcoded levels only
- **Issue:** No procedural generation; just cycles through fixed list
- **Limitation:** After ~60 levels, progression stalls
- **Fix:** Implement procedural puzzle generation for levels 60+

#### Spectrum
- **Current Max:** 10x11 grid
- **Issue:** Scaling slows significantly after level 35
- **Progression:** 3x3 → 4x4 → ... → 10x11 (then plateau)
- **Fix:** Extend to 12x12+ with procedural generation

### Limited Scaling

#### Chimp Test
- **Current Max:** 12x12 grid cap
- **Formula:** `gridSize = (9 + extra ~/ 5).clamp(9, 12)`
- **Fix:** Increase to 14x14 or higher

#### Star Battle
- **Limited hardcoded levels** (44 total) before procedural
- **Fix:** Lower procedural threshold, increase difficulty of procedural puzzles

### Games with Good Scaling ✅

**Grid Path** — Infinite procedural generation  
**Odd Color Out** — Scales to 9x9 with decreasing color differences  
**Colour Link** — Procedural generation after level 35  
**Color Flood** — Procedural generation after level 35  

## Scaling Recommendations

| Priority | Game | Action | Impact |
|----------|------|--------|--------|
| **High** | Circuit Guide | Remove hardcoded max, enable 6x6/7x7 | Player retention at high levels |
| **High** | Mine Finder | Increase clamp to 16+ | ~20 additional levels before plateau |
| **High** | Pattern Lock | Remove 5x5 cap | Infinite progression potential |
| **Medium** | Sudoku | Add procedural generation for 60+ | Extends endgame significantly |

## The Real Issue: Genre Scaling Problem

**User Insight:** Unstashing word games won't work because:
1. Word games are hard to procedurally create
2. They're tough to scale up in difficulty
3. Procedural generation requires valid dictionary validation
4. Difficulty curve is unpredictable (unlike logic puzzles where grid size = difficulty)

**Similarly, Memory/Reaction games get boring because:**
- Each level is just "do the same mechanic but harder/faster"
- The mechanic doesn't evolve, only the parameters
- Logic puzzles stay fresh because each puzzle is different

## Strategic Recommendation

**Accept the imbalance and lean into it:**

CogniQ is fundamentally a **logic puzzle platform**, not a well-rounded brain training app. This is a strength, not a weakness.

### Game Addition Strategy

Instead of forcing cognitive diversity, add 4-5 **high-quality logic games** that:
- Scale naturally through difficulty
- Stay fresh/engaging at high levels
- Add mechanical variety to logic puzzles

| Game | Why | Scaling Strategy | Addition Priority |
