------------------------------------------------------------------------
 COLUMN / TERM MEANINGS
------------------------------------------------------------------------
 - Location    : Play Console > Monetise > Products. Everything except
                 CogniQ Plus goes under "In-app products (one-time)".
 - Consumable  : Decided by CODE, not the console.
                 Consumable   = repurchasable (points get spent) -> must
                                be CONSUMED in code after granting, or the
                                user can never buy it again.
                 Non-consumable = owned once (remove ads / bundle).
 - Price       : Enter the Rs value in "Set prices"; Google auto-converts
                 and rounds all other currencies.
 - Value ladder: Points-per-rupee rises with each tier
                 (17 -> 20 -> 20 -> 23 pts/Rs). Intentional — nudges
                 buyers toward the bigger packs.
