## Executive Summary

CogniQ is positioned as a **logic puzzle mindfulness app**. The 12-month roadmap focuses on:

1. **Q3 2026 (Now):** Fix critical issues + add core logic games
2. **Q4 2026:** Expand game library + retention mechanics
3. **Q1 2027:** Social/community features + seasonal content
4. **Q2 2027:** Advanced features + personalization

**Expected Impact:** larger game library and richer engagement. Any "% improvement in retention" is unquantifiable today (no analytics) — game-count targets below are real plans; the growth columns are removed because they were invented.

# Q3 2026: FIX & FOUNDATION (Now - September 2026)

## Priority 1: Critical Fixes (Weeks 1-2)

### 1.1 User-Facing Fixes
- [ ] Achievement system: Remove auto-claim, add manual claim button
- [ ] Achievement toast: Reduce timer duration (4-5 seconds)
- [ ] NavBar alignment: Center home button icon + text in highlight
- [ ] Game screen alignment: Fix GridView card positioning
- [ ] Haptic feedback bug: Separate from sound setting

**Impact:** Improved UX, better perceived polish

### 1.2 Performance Fixes
- [ ] Fix FogOverlay setState() batching (optimize pointer events)
- [ ] Optimize word dictionary lookup (trie or cache)
- [ ] Batch daily state loading (combine SharedPreferences calls)
- [ ] Add skeleton loaders for game grids

**Impact:** Faster app feel, better performance perception

## Priority 2: Game Scaling Fixes (Weeks 2-4)

### 2.1 Scaling Plateaus
- [ ] Circuit Guide: Remove 5x5 cap, allow 6x6+ grids
- [ ] Mine Finder: Remove 13x13 cap, enable infinite scaling
- [ ] Pattern Lock: Remove 5x5 cap, allow 6x6+ grids
- [ ] Sudoku: Add procedural generation for levels 60+
- [ ] Spectrum: Extend from 10x11 to 12x12+

**Impact:** 50+ additional levels per game, ~8 weeks of new content for players

### 2.2 Add Secondary Mechanics
- [ ] Grid Path: Add "locked waypoints" at level 30+
- [ ] Odd Color Out: Add time limits, multiple tiles (see Scaling MD)
- [ ] Chimp Test: Add fading/distraction modes
- [ ] Star Battle: Add variable star counts, asymmetric grids

**Impact:** Games stay fresh through progression, better endgame retention

## Priority 3: Add First New Games (Weeks 3-6)

### 3.1 Kakuro (Arithmetic Logic)
- [ ] Implement core mechanic (cross-sum logic)
- [ ] Procedural generation with constraint solver
- [ ] 70+ level progression with scaling
- [ ] Integration with achievement system
- [ ] Visual design + animations

**Why Priority:** Fills arithmetic gap, proven popular mechanic, strong scaling

**Target:** Release by end Q3

### 3.2 Cipher Decoder (Word Logic)
- [ ] Content-feeding system (curated word lists)
- [ ] Scaling strategy: Letter diff 1→2→3, word complexity
- [ ] 70+ level progression
- [ ] Difficulty curve refinement

**Why Priority:** Only word game active, addresses vocabulary gap (if scaling works)

**Target:** Release by end Q3 or early Q4

## Q3 Success Signals (qualitative — no analytics to quantify)

- Players return after the UX fixes (achievement claim, alignment, haptic)
- More players reach high levels once scaling plateaus are removed
- Players try more than one game
- Fewer crashes / cleaner stability

# Q1 2027: ENGAGE (January - March 2027)

## Priority 1: Social & Community Features (Weeks 1-12)

### 5.1 Leaderboards (January)
- [ ] Global leaderboards (by game, all-time + monthly)
- [ ] Friend leaderboards (compare with friends)
- [ ] Clan leaderboards (small group competition)
- [ ] Regional leaderboards (by country/region)

**Why:** Drives competition, increases session frequency, viral sharing

**Target Release:** Early January

### 5.2 Friend System (January-February)
- [ ] Add/remove friends (via username or code)
- [ ] See friends' scores, streaks, achievements
- [ ] Send challenges to friends ("Beat my score on Sudoku")
- [ ] Notifications when friends achieve milestones

**Impact:** competitive players get a reason to return (unquantified)

### 5.3 Clans/Groups (February)
- [ ] Create or join clans (10-100 members)
- [ ] Clan-specific challenges
- [ ] Clan leaderboards + rewards
- [ ] Clan chat (optional, simple)
- [ ] Clan milestones (unlock perks for group)

**Why:** Community building, long-term retention, organic growth (invite friends)

**Impact:** clan membership is a strong belonging/retention driver in the genre (unquantified)

## Priority 2: Achievements & Progression (Weeks 2-10)

### 5.4 Expanded Achievement System
- [ ] Add 40+ new achievements (beyond current set)
- [ ] Achievement categories with progress bars
- [ ] Rare/legendary achievements (top 1% players)
- [ ] Achievement showcase/gallery (display on profile)
- [ ] Difficulty-based achievements (beat Sudoku level 60+)

**Impact:** More goals to pursue, extended engagement

### 5.5 Title/Badge System
- [ ] Unlock titles: "Sudoku Master", "Speed Demon", etc.

**Impact:** Status symbols drive continued play

## Priority 3: Advanced Personalization (Weeks 8-12)

### 5.6 Difficulty Profiles

### 5.7 Custom Daily Challenge
- [ ] Players select which games appear in daily challenges

**Impact:** personalized challenges may lift participation (unquantified)

## Conclusion

This 12-month roadmap balances:
- **Retention:** Fixing core issues, expanding game library
- **Engagement:** Social features, personalization, events
- **Growth:** Community building, word-of-mouth, viral mechanics
- **Sustainability:** Premium features, reasonable feature scope

**Key assumption (unproven):** social features (leaderboards + clans) are treated as the inflection point — but they require a backend the app doesn't have, and their payoff is unmeasured. Don't treat this as settled.
